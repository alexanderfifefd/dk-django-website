About this site

This site exists to test one assumption: that written content can live as markdown files on the filesystem while Django serves it like any other page.

The homepage and this page are ordinary templates. The blog is the experiment — each post is a file in content/blog/ with frontmatter for its title, date, and tags. The server parses the file when you request it, so there is nothing to rebuild and nothing to sync.

Everything here is disposable. See docs/projects/01-markdown-pages/ in the repo for the reasoning and the plan.
