# Datakollektivet — design elements (prototype 14)

Fork of [prototype 11](../11-site-design/) for trying visual components — section CTAs, hero variants,
transport chrome — on the same routes and warm brand palette.

**Project docs:** `docs/projects/14-design-elements/`

## Quick start

From this directory:

```bash
uv sync                                    # once, from the monorepo root
uv run python manage.py migrate
uv run python manage.py load_articles      # optional — dev middleware syncs on first request too
uv run python manage.py runserver
```

Open http://127.0.0.1:8000/ — **Design lab:** http://127.0.0.1:8000/design-lab/

Compare with prototype 11 (`prototypes/11-site-design/`) for palette baseline without component experiments.
