# dk-django-website

Prototypes exploring a Django website whose written content is authored as markdown files.

- **Orientation**: `docs/overview.md`
- **What's being explored and why**: `docs/projects/index.md`
- **Run the current prototype**: `uv sync`, then from `prototypes/01-markdown-pages/` run
  `uv run python manage.py migrate` once and `uv run python manage.py runserver`.
