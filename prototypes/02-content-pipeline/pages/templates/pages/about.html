About this site

This site exists to test one assumption: that markdown files can stay the source of truth for content while the database does the serving.

The homepage and this page are ordinary templates. The blog is the experiment — each post is a file in content/blog/, and manage.py ingest validates its frontmatter strictly, renders the markdown, and syncs it into a Post table. The database is derived: flush it, re-run ingest, and it comes back identical.

Everything here is disposable. See docs/projects/content-pipeline/ in the repo for the reasoning and the plan.
