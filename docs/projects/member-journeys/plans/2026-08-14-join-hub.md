# Plan: Join page as entry hub

**Project**: `member-journeys`
**Discussion**: `docs/projects/member-journeys/discussions/join-as-entry-hub.md`
**Prototype**: `prototypes/07-initiatives/`
**Status**: superseded by [three-paths-to-participate.md](../discussions/three-paths-to-participate.md)

## Goal

Rebuild `/join/` as the single entry hub: SSO account, recruiting cards, membership form. Remove
recruiting strips from home and system/initiative indexes.

## Changes

| Area | Action |
|---|---|
| `/join/` | Three sections: account card, recruiting card grid, membership form |
| Home | Remove recruiting link strip; update join-cta copy |
| Index pages | Remove bottom "Looking for help" bands |
| Detail pages | Link to Join anchors (`#open-roles`, `#membership`) |
| CSS | Join hub + recruiting card grid |

## Outcome

- Join page frames participation-first; SSO is the shared first step
- Recruiting items render as distinct cards (initiative/system lane colours)
- Home and indexes no longer duplicate recruiting as plain lists
- List badges and detail asides unchanged
